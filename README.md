# Tamajaq · OntoLex

An attempt to explore the Tamajaq–French dictionary, understand its structure, visualize it, and work towards an OntoLex implementation.

**Live viewer:** https://jehadoumer.github.io/Tamajaq-Ontolex-Project/

Reference: Mangeot & Enguehard (2013), « Des dictionnaires éditoriaux aux représentations XML standardisées », in *Ressources Lexicales*, John Benjamins.
